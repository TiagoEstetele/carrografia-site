Política de Privacidade

Esta política vale para o site Carrografia e para a ferramenta Carrografia Publicador.

1. Quem usa a ferramenta

A ferramenta é usada somente pelo dono do canal Carrografia, para publicar vídeos nas contas do próprio canal. Ela não é oferecida a outras pessoas.

2. Dados acessados

  • YouTube (Google): permissão para enviar vídeos e editar os metadados (título, descrição, tags, miniatura e playlists) do canal Carrografia.
  • TikTok: informações básicas do perfil (nome e foto) e permissão para enviar vídeos e publicar na conta do Carrografia.

Não coletamos dados de espectadores, seguidores ou de qualquer outra pessoa.

3. Como os dados são usados

Os tokens de acesso servem apenas para enviar e publicar os vídeos do canal. Não vendemos, compartilhamos nem usamos esses dados para publicidade.

4. Armazenamento e segurança

Os tokens ficam guardados como credenciais protegidas no ambiente de automação do dono do canal e nunca são publicados.

5. Revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions (Google) e nas configurações de segurança do TikTok (Apps e serviços conectados).

6. Uso de dados do Google

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. A ferramenta também usa os Serviços de API do YouTube, sujeitos aos Termos de Serviço do YouTube e à Política de Privacidade do Google.

7. Contato

Dúvidas: carrografiabr@gmail.com.

English summary

Carrografia Publisher is used only by the channel owner. It accesses only the channel's own YouTube and TikTok accounts to upload and publish the channel's videos. No data from other users is collected, sold or shared. Access can be revoked at any time.
